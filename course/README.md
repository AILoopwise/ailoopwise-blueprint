# AILoopwise Blueprint · Die Anleitung zur Videoreihe

**Deutsch** · [English](#english)

Das ist die Textanleitung zu den sechs Folgen der Videoreihe. Jede Seite ist die schriftliche Form einer Folge: was du installierst, was du tippst, der genaue Prompt zum Einfügen, ein Beispiel zum Kopieren und die eine Sache, die du vor der nächsten Folge erledigst.

## Die sechs Folgen

1. [Installation](01-installation.md): Claude Code installieren, anmelden, erste Session.
2. [Desktop einrichten](02-desktop-setup.md): VS Code, die Erweiterung und dein erstes Projekt mit einem einzigen Prompt.
3. [Server (optional)](03-server-optional.md): Claude Code auf einem eigenen Server, abgeschottet mit Docker und Tailscale, gesteuert vom Handy.
4. [Leitplanken](04-guardrails.md): was die Hooks wirklich blockieren, die drei Aufgabendateien, Sicherung im privaten GitHub-Repo.
5. [Projektstart per Sprache](05-voice-kickoff-prd.md): im Sprachchat zum PRD, dann `/new-project`.
6. [Lange Sitzungen](06-long-sessions.md): Unter-Agenten, Reviewer, Fortsetzungs-Prompt und `/clear`.

**Folge 3 ist optional.** Alles ab Folge 4 funktioniert auch ohne Server, direkt auf deinem Laptop.

## So nutzt du die Anleitung mit den Videos

- Schau zuerst das Video, damit du weißt, wie es aussieht. Dann arbeite die Seite Schritt für Schritt ab.
- Befehle stehen in grauen Blöcken, Prompts zum Einfügen in `text`-Blöcken. Kopier sie vollständig.
- Die Installationsbefehle für Claude Code, Docker und Tailscale stehen hier absichtlich nicht. Sie ändern sich; nimm immer die verlinkte offizielle Seite.
- Folge 1 bis 5 enden mit „Sag deiner KI“: einem Prompt, den du in Claude Code einfügst, damit es die Schritte der Folge mit dir prüft. In Folge 6 ist das der Fortsetzungs-Prompt.
- Hakt etwas, sieh zuerst unter „Wenn etwas hakt“ am Ende der Seite nach.
- Alle Dateien zum Kopieren liegen in [examples/](examples/): PRD-Vorlage und -Beispiel, eine Projekt-CLAUDE.md, die drei Aufgabendateien, der Brainstorming-Prompt, der Fortsetzungs-Prompt und die Server-Checkliste.

## Was du brauchst

Ein bezahltes Claude-Abo (Pro, Max, Team oder Enterprise) oder ein Console-Konto und einen Rechner. Das Setup-Paket selbst ist gratis.

Alle Beispiele in `examples/` (Verein, Projekt, Inhalte) sind erfunden.

## English

This is the text guide to the six episodes of the video series. Each page is the written form of one episode: what to install, what to type, the exact prompt to paste, an example to copy, and the one thing you do before the next episode.

### The six episodes

1. [Install](01-installation.md): install Claude Code, sign in, first session.
2. [Desktop setup](02-desktop-setup.md): VS Code, the extension and your first project from one single prompt.
3. [Server (optional)](03-server-optional.md): Claude Code on a server of your own, sealed off with Docker and Tailscale, driven from your phone.
4. [Guardrails](04-guardrails.md): what the hooks really block, the three task files, backup to a private GitHub repo.
5. [Kick-off by voice](05-voice-kickoff-prd.md): from a voice chat to a PRD, then `/new-project`.
6. [Long sessions](06-long-sessions.md): subagents, reviewer, continuation prompt and `/clear`.

**Episode 3 is optional.** Everything from episode 4 on also works without a server, right on your laptop.

### How to use it with the videos

- Watch the video first so you know what it looks like. Then work through the page step by step.
- Commands sit in grey blocks, prompts to paste in `text` blocks. Copy them in full.
- The install commands for Claude Code, Docker and Tailscale are deliberately not printed here. They change; always use the linked official page.
- Episodes 1 to 5 end with "Tell your AI": a prompt you paste into Claude Code so it checks the episode's steps with you. In episode 6 that is the continuation prompt.
- If something breaks, check "If something goes wrong" at the end of the page first.
- Every file to copy lives in [examples/](examples/): PRD template and example, a project CLAUDE.md, the three task files, the brainstorming prompt, the continuation prompt and the server checklist.

### What you need

A paid Claude plan (Pro, Max, Team or Enterprise) or a Console account, and a computer. The setup pack itself is free.

Every example in `examples/` (club, project, content) is fictional.
